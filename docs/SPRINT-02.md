# Sprint 2 — Trust & Reliability

## Goal
The user should always know the state of Violet Ember.

## Scope
- Doctor Engine
- Backup Manager
- Accent validation
- Portable diagnostics

## Completion Criteria
- `violet-ember doctor` reports shell, config, accent, CLI, backup and root status.
- `violet-ember backup list` shows available backups.
- `violet-ember backup create` creates a manual backup.
- Accent changes validate required variables before applying.
