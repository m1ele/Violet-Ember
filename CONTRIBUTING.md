# Contributing

Before opening a Pull Request, ask yourself:

1. Does this improve readability?
2. Does this respect semantic colors?
3. Does this preserve simplicity?
4. Does this improve the user experience?
5. Is it worth maintaining?

## Accent Pack rules

Accent Packs may customize user identity only.
They must not redefine root, errors, warnings, or semantic states.

Root remains Ember.
