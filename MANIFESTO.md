# ◆ Violet Ember ◆ Manifesto

Minimal.

Reliable.

Readable.

Predictable.

Beautiful because it is simple.

Every line exists for a reason.

Violet Ember does not try to be flashy.
It tries to disappear while you work.

We do not design features.
We design where features belong.

Easy things should be easy.
Advanced things should still be possible.
