# Quality Checklist

A Violet Ember module is considered stable when:

- [ ] Single Responsibility
- [ ] Internal API compliant
- [ ] No duplicated code
- [ ] No legacy files
- [ ] ShellCheck clean
- [ ] Self-test covered
- [ ] Readability approved

## Repository Structure

Required directories:

- `.github/`
- `assets/`
- `bin/`
- `commands/`
- `core/`
- `docs/`
- `docs/adr/`
- `docs/guides/`
- `lib/`
- `tests/`
- `themes/`
- `themes/official/`
- `themes/root/`
- `themes/user/`

Required root files:

- `README.md`
- `MANIFESTO.md`
- `PHILOSOPHY.md`
- `STYLE.md`
- `DESIGN.md`
- `ARCHITECTURE.md`
- `ROADMAP.md`
- `CHANGELOG.md`
- `CONTRIBUTING.md`
- `CHARTER.md`
- `LICENSE`
- `install.sh`
- `uninstall.sh`
